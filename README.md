Production-grade Next.js 16 frontend for the **Chancen** professional social network platform.

---

## 🌟 Key Features

- **Dynamic Feed**: Rich post creation (image uploads, character counts, emoji tools), multi-reaction likes, threaded comments, and reposts.
- **People & Network Discovery**: Follow/Connect flows, interactive Followers/Following modals with in-modal search, and intelligent recommendation cards.
- **Real-Time WebSockets**: Live chat messaging and unread badge counters across navigation headers.
- **Search System**: Multi-category search dropdown and full-page `/search` route with tab filters (*All*, *People*, *Posts*, *Jobs*).
- **Jobs & Hiring**: Job discovery, salary/location filtering, and 1-click application submission.
- **Resilient UI**: Error boundaries, accessible modals, framer-motion micro-interactions, dark/light theme switching.

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000).
